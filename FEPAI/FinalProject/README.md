# README

## Overview

本项目实现一个benchmark并用其编写期末论文。

总体来说，给定一条电影评论文本 $x$，模型需要判断其情感极性 $y \in \{positive, negative\}$。评论将依据文本长度划分为短、中、长三个区间并将三个长度的文本情感分析作为三个任务，以考察模型对不同长度输入的鲁棒性与理解能力。评估的对象将分为小模型与LLM，对每组对象评估它们对不同长度的文本理解能力并作出比较。
